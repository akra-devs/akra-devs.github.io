プロダクトをつくり、 自分たちで運用します。

Akra Dev は、開発者が企画・リリース・運用まで担当するプロダクトチームです。仕事の 80% を自社サービスに、20% をパートナープロジェクトに使います。

運用で直面した問題を、次のプロダクトとパートナーの仕事に反映します。

80%

自社サービス開発

私たちは市場の課題を探し、解決し続けます。SaaS や B2C プラットフォームなどを実際に運営し、長く使われるプロダクトのつくり方を学びました。

20%

最適なパートナーシップ

技術が事業の中核となるプロジェクトに参加します。要件、プロダクト構造、リリース後の運用まで一緒に検討します。

合う技術を選びます

プロジェクトに合う 使い慣れた技術を選びます。 運用の安定性と保守コストをあわせて考えます。

アプリ開発

Flutter で iOS と Android を同時に開発し、リリース速度と使い心地を両立させます。

ウェブサービス

React と Next.js を基盤に、ランディングページから複雑なダッシュボードまで高速なウェブアプリをつくります。

クラウドインフラ

AWS と Google Cloud 上で、トラフィック変動に耐えるサーバー構成を設計します。

MVP とスケールアップ

アイデア検証のための MVP から、運営中サービスの改善まで、段階に合わせて伴走します。

このようにつくります

課題と画面の流れを先に揃え、 小さくつくって検証します。 決定事項と次の作業は記録に残します。

  1. 01

    課題を整理する

    何をつくるかの前に、なぜ必要なのかを合わせます。

  2. 02

    体験の流れを設計する

    ユーザーが実際に通る画面と導線を先に整理します。

  3. 03

    開発

    運営を見据えた構造で機能を小さく分け、安定してつくります。

  4. 04

    リリース

    検証してリリースし、運用中に確認する改善項目を記録します。
